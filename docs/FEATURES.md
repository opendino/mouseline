# Feature plan

Status legend: ✅ done · 🚧 in progress · ⏳ later (needs a decision or outside resources)

## Recognition
| Feature | Status | Notes |
|---|---|---|
| 32 built-in shapes, direction-sensitive $1 recognizer | ✅ | `MGesturesCore/Recognizer.swift` |
| Shapes without an action act as a normal right click | ✅ | |
| **Custom gestures** — draw and name your own shapes | ✅ | Stored normalized in the config; warns when too similar to an existing shape |
| **Try-it area** — draw in Settings and see the top matches with distances | ✅ | Helps tune the tolerance |
| Basic / all shapes view | ✅ | Basic = lines, diagonals and custom gestures |

## Triggering
| Feature | Status | Notes |
|---|---|---|
| Right button, Esc to cancel, hold still for the context menu | ✅ | |
| **Trigger button**: right or middle button | ✅ | |
| **Required modifier** (none / ⌥ / ⌃ / ⌘ / ⇧) | ✅ | Gestures only while the modifier is held |
| **Global shortcut** to turn gestures on/off | ✅ | Carbon hot key — needs no keyboard monitoring |
| Excluded apps + "Disable in current app" | ✅ | |

## Actions
| Feature | Status | Notes |
|---|---|---|
| Tile left/right, maximize, minimize, back/forward, shortcut, open app/URL, shell | ✅ | |
| **Window**: tile top/bottom, center, move to next display, full screen, close | ✅ | Accessibility API |
| **App**: hide, quit | ✅ | |
| **System**: Mission Control, show desktop, lock screen, sleep display | ✅ | |
| **Media**: play/pause, next/previous track, volume up/down, mute | ✅ | System-defined media key events |
| **Run AppleScript** | ✅ | Needs the Apple Events entitlement + per-app Automation consent |
| **Per-app bindings** — override any gesture for one app | ✅ | The app under the cursor decides |
